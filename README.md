# 黎深桌宠 · Lishen Desktop Pet

一只会陪你的桌面小宠物，支持 **macOS** 和 **Windows 11** 双平台：

- macOS 版基于 **PySide6**，双击 `.command` 一键启动（首次自动建环境装依赖）。
- Windows 11 版是**原生 PowerShell + .NET WinForms** 实现，无需安装 Python。

完整功能、安装步骤、手动命令和双平台入口请阅读：

[`lishen-pet/README.md`](lishen-pet/README.md)

快速入口：

- macOS：双击 `lishen-pet/启动黎深.command`
- Windows 11：无需安装 Python，直接双击 `lishen-pet/启动黎深-Windows.cmd`
- 默认角色是星星（沈星回），托盘菜单可切换黎深
