# 黎深桌宠 · 安装与使用说明

桌面上一只会动的小黎深，坐在他的冰淇淋沙发里。到点了会弹气泡关心你，
戳一下他会有反应。所有台词都在 `data/lines.json`，你可以随时自己改。

---

## 一、macOS 启动

1. 把整个 `lishen-pet` 文件夹放到你想放的位置。
2. 双击 **`启动黎深.command`**。
   - 第一次运行会自动创建环境并联网安装依赖，大约 1–2 分钟。
   - 之后再启动会直接复用 `.venv`。
3. 想开机自启，双击 **`设置开机自启.command`**。

如果提示来自身份不明的开发者，在文件上右键选择“打开”，再确认一次即可。

## 二、Windows 11 启动（无需 Python）

Windows 默认版本使用系统自带的 PowerShell 5.1 和 .NET WinForms，不需要安装 Python 或 PySide6。

1. 双击 **`启动黎深-Windows.cmd`**。
2. 想开机自动启动，双击 **`设置开机自启-Windows.cmd`**；取消则双击 **`取消开机自启-Windows.cmd`**。
3. 如果没有显示，双击 **`诊断-Windows.cmd`** 查看诊断报告。

Windows 自启使用当前用户的 Startup 文件夹，不需要管理员权限，也不会改动系统服务。

也可以手动运行：

```powershell
cd lishen-pet
wscript.exe .\windows\launch-native.vbs
```

如果你需要开发或调试 PySide6 版本，仍可使用 **`启动黎深-Windows-Python.cmd`**，该入口才需要 Python 3.12/3.13。

## 三、怎么用

- **戳他**：鼠标点一下小黎深，他会冒一句话。
- **搬家**：按住他拖动，可以放到屏幕任何角落。
- **悬挂星星**：使用星星时，拖到当前屏幕左侧或右侧边缘并松开，会显示对应的拎喵动作并自动吸附；再次拖离侧边即可恢复普通随机动作。
- **悬挂互动**：悬挂期间不会切换拎喵动作，点击星星只会使用悬挂专属台词。
- **状态互动**：可从菜单开始 25 分钟专注、庆祝完成任务或陪角色发呆；正常桌面状态长时间无操作会逐渐进入发呆和困倦动作。
- **甩飞互动**：快速把桌宠甩出去，会暂时消失，几秒后气鼓鼓地回来。
- **安静待机**：定时关心只显示桌宠头顶气泡，不再弹 Windows 右下角系统通知。
- **显示控制**：透明度可选 100% / 80% / 60% / 40%；开启鼠标穿透后，需从系统托盘菜单关闭穿透。
- **菜单栏 / 系统托盘图标**：让角色说句话、显示 / 隐藏桌宠、暂停 / 恢复提醒、重启桌宠、退出。
- **切换角色**：右键系统托盘图标 → **切换角色**，可选择星星或黎深，默认是星星。

## 四、他什么时候会主动说话

| 时机 | 内容 |
|------|------|
| 每小时（带 ±12 分钟随机，7:00–23:00） | 日常关心 / 想你 / 打气 / 天气 |
| 中午 11 点 | 提醒点午饭 |
| 傍晚 18 点 | 提醒吃晚饭 |
| 夜里 23:30 | 哄你睡觉 |
| 刚启动时 | 打个招呼 |

想改时间：打开 `main.py` 顶部配置区，修改 `LUNCH_HOUR`、`DINNER_HOUR`、`HOURLY_JITTER` 等值。

## 五、自己加台词 / 改台词

用文本编辑器打开 `data/lines.json`，按现有格式在对应分类里加句子即可。

- 顶层 `categories`：黎深台词。
- `characters.star.categories`：星星专属台词。
- `characters.star.categories.drag_left` / `drag_right`：星星向左右拖拽释放时的台词。
- `characters.star.categories.hanging`：星星悬挂时点击使用的台词。

- `greeting` 开场问候　`daily` 日常关心　`night` 深夜哄睡
- `cheer` 鼓励打气　`miss` 想你撒娇　`weather` 天气节气
- `lunch` 午饭　`dinner` 晚饭　`poke` 被戳互动

每类至少留一句。改完保存并重新启动黎深即可生效。

## 六、诊断与自检

Windows 用户可双击：

- `诊断-Windows.cmd`：生成 `诊断报告-Windows.txt`。
- `测试主程序-Windows.cmd`：运行 3 秒并生成 `主程序测试输出.txt`。

遇到问题时，把上述报告以及 `error.log`、`run.log` 一起提供出来。
